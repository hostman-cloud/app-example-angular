# Angular

Example of an [Angular](https://angular.dev/) application that can be deployed to **Hostman** without configuration.

:tada: [Demo](https://hostman-cloud-app-example-angular-59ad.hostman.dev/)

:rocket: [Create your Apps](https://hostman.com/my/apps/create)

:books: [Hostman Apps Documentation](https://hostman.com/docs/app-platform/backend-apps/)

## <a name="dev"></a>Running locally

```bash
# install dependencies
npm install

# run in development mode with file watching
npm start

# build for production with minification
npm run build
```
